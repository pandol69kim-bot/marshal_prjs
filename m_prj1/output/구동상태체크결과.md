## 백엔드 마지막 실행 오류 (backend/run.log)

```
BUILD FAILURE
Caused by: java.lang.IllegalArgumentException: redirectUri cannot be empty
  at ClientRegistration$Builder.validateAuthorizationCodeGrantType
```

### 원인 분석

`application-local.yml`에 Spring Security OAuth2 client registration의 `redirect-uri`가 누락되어 있음.

`app.oauth2.redirect-uri`는 커스텀 설정이며, Spring Security가 요구하는
`spring.security.oauth2.client.registration.*.redirect-uri`와 별개임.

### 수정 필요 항목 (`backend/src/main/resources/application-local.yml`)

```yaml
spring:
  security:
    oauth2:
      client:
        registration:
          google:
            client-id: dummy-google-client-id
            client-secret: dummy-google-client-secret
            redirect-uri: http://localhost:8080/login/oauth2/code/google  # 추가 필요
          kakao:
            client-id: dummy-kakao-client-id
            client-secret: dummy-kakao-client-secret
            redirect-uri: http://localhost:8080/login/oauth2/code/kakao   # 추가 필요
```

## 구동 방법

### 방법 1 — Docker Compose 전체 기동 (권장)

```bash
# .env 파일에 실제 값 설정 후
docker-compose up -d
```

### 방법 2 — 로컬 개발 모드

```bash
# 1. 인프라만 먼저 기동
docker-compose up -d postgres redis minio

# 2. 백엔드 (local 프로파일)
cd backend
./mvnw spring-boot:run -Dspring-boot.run.profiles=local

# 3. 프론트엔드
cd frontend
npm install
npm run dev
```

## 즉시 수정 필요 사항

1. **`application-local.yml`에 OAuth2 `redirect-uri` 추가** — 백엔드 기동 오류 직접 원인
2. **`.env`에 실제 `JWT_SECRET` 설정** — 최소 32자 이상
3. **Google / Kakao OAuth2 실제 사용 시** Client ID / Secret 발급 및 등록 필요

## 특이사항

- `backend/run.log` 파일이 Wide-char(UTF-16 like) 인코딩으로 기록되어 있어 가독성 낮음
