# 프론트엔드 Docker 작업 계획

## 현황 분석

### 현재 Docker 구성 (backend/docker-compose.yml)
| 서비스 | 이미지 | 포트 |
|--------|--------|------|
| postgres | postgres:16-alpine | 5432 |
| redis | redis:7-alpine | 6379 |
| minio | minio/minio | 9000, 9001 |

- 백엔드 앱 자체는 Docker에 없음 (mvnw.cmd로 직접 실행)
- 프론트엔드 Dockerfile 없음

### 프론트엔드 스택
- Vue 3 + Vite + TypeScript
- 개발 서버: 포트 5173
- vite.config.ts의 proxy: `/api`, `/oauth2` → `http://localhost:8080` (백엔드)

---

## 가능 여부 결론

**가능합니다.** 두 가지 방식으로 Docker화할 수 있습니다.

| 방식 | 특징 | 용도 |
|------|------|------|
| **개발 모드** (Dockerfile.dev) | Vite dev server, 소스 핫리로드 | 로컬 개발 |
| **프로덕션 모드** (Dockerfile) | 멀티스테이지 빌드 + nginx | 배포/통합 테스트 |

## 작업 계획

### Step 1: 프로젝트 구조 재편
현재 `backend/docker-compose.yml`을 **프로젝트 루트**로 이동

```
output/project/
├── docker-compose.yml          ← 이동 (backend/ → project/)
├── docker-compose.dev.yml      ← 신규 (개발 환경 오버라이드)
├── backend/
│   ├── Dockerfile              ← 신규 (백엔드 이미지)
│   └── ...
└── frontend/
    ├── Dockerfile              ← 신규 (프로덕션: 멀티스테이지 + nginx)
    ├── Dockerfile.dev          ← 신규 (개발: Vite dev server)
    └── nginx.conf              ← 신규 (SPA + API 프록시)
```

---

### Step 2: frontend/Dockerfile (프로덕션 — 멀티스테이지)

```dockerfile
# ---- Stage 1: Build ----
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
ARG VITE_API_BASE_URL
ARG VITE_OAUTH2_GOOGLE_URL
ARG VITE_OAUTH2_KAKAO_URL
RUN npm run build

# ---- Stage 2: Serve ----
FROM nginx:1.25-alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

**핵심**: Vite 빌드 시 `VITE_*` 환경변수가 JS 번들에 정적으로 삽입됨 → ARG로 빌드 타임에 주입 필요

---

### Step 3: frontend/Dockerfile.dev (개발 — 핫리로드)

```dockerfile
FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
EXPOSE 5173
CMD ["npm", "run", "dev", "--", "--host", "0.0.0.0"]
```

**핵심**: `--host 0.0.0.0` 옵션 필수 — 없으면 컨테이너 외부에서 접근 불가

---

### Step 4: frontend/nginx.conf

```nginx
server {
    listen 80;
    root /usr/share/nginx/html;
    index index.html;

    # Vue Router SPA 폴백 (새로고침 시 404 방지)
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 백엔드 API 프록시 (vite proxy 대체)
    location /api {
        proxy_pass http://backend:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # OAuth2 프록시
    location /oauth2 {
        proxy_pass http://backend:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /login {
        proxy_pass http://backend:8080;
        proxy_set_header Host $host;
    }
}
```

**핵심**: nginx에서 `http://backend:8080`은 Docker 네트워크 내 서비스명으로 라우팅

### Step 5: backend/Dockerfile

```dockerfile
FROM eclipse-temurin:21-jdk-alpine AS builder
WORKDIR /app
COPY .mvn/ .mvn/
COPY mvnw pom.xml ./
RUN chmod +x mvnw && ./mvnw dependency:go-offline -B
COPY src ./src
RUN ./mvnw package -DskipTests

FROM eclipse-temurin:21-jre-alpine
WORKDIR /app
COPY --from=builder /app/target/*.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java", "-jar", "app.jar"]
```

### Step 6: docker-compose.yml (루트 통합본)

```yaml
services:
  postgres:
    image: postgres:16-alpine
    ports:
      - "5432:5432"
    environment:
      POSTGRES_DB: appdb
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
    volumes:
      - pgdata:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres"]
      interval: 10s
      timeout: 5s
      retries: 5

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
    command: redis-server --appendonly yes
    volumes:
      - redisdata:/data

  minio:
    image: minio/minio:latest
    ports:
      - "9000:9000"
      - "9001:9001"
    environment:
      MINIO_ROOT_USER: minioadmin
      MINIO_ROOT_PASSWORD: minioadmin
    command: server /data --console-address ":9001"
    volumes:
      - miniodata:/data

  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    ports:
      - "8080:8080"
    environment:
      SPRING_PROFILES_ACTIVE: prod
      DATABASE_URL: jdbc:postgresql://postgres:5432/appdb
      DATABASE_USERNAME: postgres
      DATABASE_PASSWORD: postgres
      REDIS_HOST: redis
      JWT_SECRET: ${JWT_SECRET}
      GOOGLE_CLIENT_ID: ${GOOGLE_CLIENT_ID}
      GOOGLE_CLIENT_SECRET: ${GOOGLE_CLIENT_SECRET}
      KAKAO_CLIENT_ID: ${KAKAO_CLIENT_ID}
      KAKAO_CLIENT_SECRET: ${KAKAO_CLIENT_SECRET}
    depends_on:
      postgres:
        condition: service_healthy
      redis:
        condition: service_started

  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
      args:
        VITE_API_BASE_URL: ""
        VITE_OAUTH2_GOOGLE_URL: /oauth2/authorization/google
        VITE_OAUTH2_KAKAO_URL: /oauth2/authorization/kakao
    ports:
      - "80:80"
    depends_on:
      - backend

volumes:
  pgdata:
  redisdata:
  miniodata:
```

---

### Step 7: docker-compose.dev.yml (개발 오버라이드)

```yaml
# 사용법: docker compose -f docker-compose.yml -f docker-compose.dev.yml up
services:
  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile.dev
    ports:
      - "5173:5173"
    volumes:
      - ./frontend/src:/app/src       # 소스 핫리로드
      - ./frontend/public:/app/public
    environment:
      VITE_API_BASE_URL: http://localhost:8080
      VITE_OAUTH2_GOOGLE_URL: http://localhost:8080/oauth2/authorization/google
      VITE_OAUTH2_KAKAO_URL: http://localhost:8080/oauth2/authorization/kakao
```

---

### Step 8: vite.config.ts 수정

개발 모드 Docker 환경에서 프록시 target을 환경변수로 받도록 수정

```typescript
server: {
  port: 5173,
  host: '0.0.0.0',   // Docker 컨테이너 외부 접근 허용
  proxy: {
    '/api': {
      target: process.env.VITE_API_TARGET || 'http://localhost:8080',
      changeOrigin: true
    },
    '/oauth2': {
      target: process.env.VITE_API_TARGET || 'http://localhost:8080',
      changeOrigin: true
    }
  }
}
```

## 실행 방법 (완성 후)

### 프로덕션 전체 스택 실행
```powershell
cd output/project
docker compose up -d --build
# 접속: http://localhost (nginx 80포트)
```

### 개발 모드 (핫리로드)
```powershell
cd output/project
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d
# 접속: http://localhost:5173
```

### 인프라만 실행 (기존 방식 유지)
```powershell
cd output/project
docker compose up -d postgres redis minio
# 백엔드: .\mvnw.cmd spring-boot:run
# 프론트: npm run dev
```

## 주요 고려사항

| 항목 | 내용 |
|------|------|
| VITE 환경변수 | 빌드 타임에 번들에 삽입됨. 런타임 주입 불가 → Docker ARG로 전달 |
| API 프록시 | 프로덕션은 nginx가 처리, 개발은 Vite dev server가 처리 |
| OAuth2 Redirect URI | Docker 환경에서 `http://localhost/login/oauth2/code/google` 로 변경 필요 |
| 핫리로드 | Dockerfile.dev + volume mount 조합으로 구현 |
| .env 파일 | JWT_SECRET 등 민감 정보는 프로젝트 루트 `.env`에서 관리 |
| Windows 주의 | mvnw 파일 줄바꿈(CRLF→LF) 변환 필요할 수 있음 (`git config core.autocrlf false`) |
