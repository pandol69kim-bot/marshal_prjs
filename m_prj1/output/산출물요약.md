## 핵심 구현 포인트

### 백엔드 (Spring Boot)

| 항목 | 구현 방식 |
|------|---------|
| 외부 API 호출 (동기) | `@FeignClient` 선언적 인터페이스 + `ErrorDecoder`로 에러 변환 |
| 외부 API 호출 (비동기) | `WebClient` + retry/timeout + 에러 처리 |
| 장애 전파 차단 | `Resilience4j` Circuit Breaker + Fallback |
| 외부 호출 자동 로깅 | `ExternalApiLoggingAspect` AOP |
| 인증/인가 | Spring Security 6 + JWT (Access 15분 / Refresh 7일 HttpOnly Cookie) |
| 소셜 로그인 | OAuth2 Client (Google, Kakao) → 내부 JWT 발급 |
| 공통 응답 포맷 | `ApiResponse<T>` + RFC 7807 에러 포맷 |
| 전역 예외 처리 | `@RestControllerAdvice` + `ErrorCode` 열거형 |
| DB 마이그레이션 | Flyway SQL 기반 버전 관리 |
| 파일 업로드 | AWS S3 SDK (Presigned URL 방식) |
| 비동기 알림 | `@Async` + SendGrid (Email) / NCP SMS |

### 프론트엔드 (Vue 3)

| 항목 | 구현 방식 |
|------|---------|
| HTTP 클라이언트 | Axios + Request/Response Interceptor |
| 토큰 자동 갱신 | 401 응답 시 큐잉(queue) 방식 재시도 |
| 상태 관리 | Pinia (`useAuthStore`) |
| 서버 상태 | TanStack Query Vue (`useResourceList`, `useCreateResource` 등) |
| 라우트 보호 | Vue Router `beforeEach` navigation guard |
| 폼 검증 | VeeValidate 4 + Zod schema |
| OAuth2 | 소셜 로그인 후 callback 페이지에서 토큰 처리 |
| 알림 UI | `useToast` composable + `ToastContainer` 컴포넌트 |
| 페이지네이션 | `BasePagination` 컴포넌트 + `usePagination` composable |

## 아키텍처 다이어그램 (요약)

```
[Vue 3 SPA]
    │ HTTPS + JWT Bearer
    ▼
[Spring Boot 3.3]
    ├── Spring Security (JWT + OAuth2)
    ├── REST Controllers (ApiResponse<T>)
    ├── Service Layer (@Transactional)
    ├── Repository (Spring Data JPA)
    │
    ├── [PostgreSQL 16]  ← 메인 DB (Flyway 마이그레이션)
    ├── [Redis 7]        ← 캐시 / 토큰 블랙리스트
    │
    └── External Systems (Feign + WebClient + Resilience4j)
        ├── Google / Kakao OAuth2
        ├── SendGrid (Email)
        ├── NCP SMS
        ├── AWS S3 / MinIO (파일)
        └── 기타 외부 REST API
```

## 개발 착수 순서 (권장)

1. **Phase 1** (2주) — Spring Boot 초기 설정, Flyway 스키마, JWT 인증, Vue 프로젝트 + Axios interceptor
2. **Phase 2** (2주) — CRUD REST API + 페이지네이션, Vue 페이지/컴포넌트, TanStack Query
3. **Phase 3** (2주) — OAuth2 소셜 로그인, Feign Client 외부 연동, 알림 서비스
4. **Phase 4** (1주) — Circuit Breaker, 테스트 커버리지 80%+, Swagger 문서화
